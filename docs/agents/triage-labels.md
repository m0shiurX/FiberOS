# Triage Labels

This project uses the five canonical triage roles, each label string equal to its name:

- `needs-triage` — newly created, not yet triaged
- `needs-info` — needs more information before it can be triaged
- `ready-for-agent` — triaged and ready for implementation by an agent
- `ready-for-human` — triaged and ready for implementation by a human
- `wontfix` — identified as not to be fixed
